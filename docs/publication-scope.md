# Public release scope

This repository publishes a small, inspectable derivative of the prototype. It includes current mechanics and validators, a declared input format, original tiny test media, tests, design documentation and summarized historical case studies, and the static 3DCodeVerse study UI source.

## Included

| Material | Reason | Evidence status |
|---|---|---|
| Text/selected-still CLI and schema | Smallest inspectable forecast contract | Offline tested; live account compatibility unverified here |
| Persona projection and three profiles | Understand and test audience assumptions | Authored archetypes; not interviewed people |
| Session executor and auditor | Inspect exposure, actions, clocks and citation handling | Derived from runtime 0.4; portable changes versioned separately |
| Native observer | Inspect bounded clip preparation and audio policy | Preparation/validation tested; source-semantic review still required |
| Inspection schema/validator | Distinguish citation integrity from support | No case-specific provider-comparison orchestration |
| Example articles, SVG, GIF, MP4 | Credential-free reproduction | Original authored/generated software fixtures |
| Recorded case summaries and study UI | Explain decisions, individual outcomes and limits | Earlier Opus case plus nine audited 3DCodeVerse model traces; publication makes no new inference |

The SVG is authored text/vector markup. The GIF and tone MP4 are original FFmpeg test patterns generated by [`make_example_media.py`](../scripts/make_example_media.py). They depict no real people, proprietary game or model outcome. Generated files are committed to make the first run small and offline; the generator documents their source. Exact byte identity across different FFmpeg versions is not promised. Every bundle hashes the supplied bytes and verifies its own transformations.

## Excluded

Full original article/media packages, raw model requests/responses and historical run archives, native listening clips, narrated video/production projects, browser executables, dependencies, local fonts, deployment transports/IDs, credentials, meeting notes, messages and business planning are excluded. They are unnecessary for the public first run or have separate provenance/rights concerns. The earlier Opus application and its large media payload remain linked rather than copied. The new `site/` includes only study presentation, definitions and selected results; no draft/media redistribution.

Historical raw outputs and canonical article versions were not edited or deleted to produce this derivative. Exclusions and failed comparisons remain visible in the public summary. This summary is not a complete independent reproduction archive. Publishing the code does not certify rights or technical claims in separately linked article media.

## License and reporting

No reuse license is granted by this initial public release. Dependency licenses remain in their upstream packages; linked article media retain their respective rights. If a reuse license is selected later, apply it only to material for which the maintainer has authority.

Report a suspected sensitive-data exposure privately through the repository owner's GitHub profile rather than copying it into an issue. Do not submit credentials, private articles, personal reader records or third-party media without authority. Generated run folders are ignored by Git.
