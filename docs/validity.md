# Validity and limitations

The harness separates a correct execution record from a correct prediction about a person. Passing a schema, matching a quote and replaying a clock establish specific mechanical properties. They do not establish semantic support, human predictive accuracy or editorial value.

| Evidence state | Permitted interpretation | Still unknown |
|---|---|---|
| Source reference exists | A URL/filename appeared in the article | Whether any media bytes were supplied |
| Media bytes supplied | Provider input contained that representation | Attention, understanding or complete temporal coverage |
| Sampled frame observed | The particular sample was in the request | What happened between samples |
| Citation integrity valid | Address/quote/interval meets the contract | Whether it supports the finding |
| Source-reviewed observation | Reviewer accepted the bounded statement and scope | Broader/generalized or causal claim |
| Audited live session | Requests and recorded exposure/clocks satisfy checks | Human-like attention, comprehension, calibrated prediction |
| Authored fixture | Software accepted a constructed example | Any actual model or reader behavior |

## Uncertainty

All model ranges are elicited judgments, with `coverage: unknown`, `calibration_status: not_calibrated` and `confidence_interval: null`. Multiple sampled outputs would estimate variation in model outputs under the selected setup; they would not automatically estimate uncertainty over humans. No population weights, independent reader sample or calibration mapping is supplied.

## Observation and media

A still cannot establish timing, repeated events, causal mechanics or an event's continuous absence. A requested provider sampling rate is not proof of exact sampled timestamps. Visible source labels remain claims. Media conversion logs identify frame count, timestamps, duration, codec, pad/crop and audio policy. Lossy derivatives remain derivatives.

The native observer can be sound-enabled for one declared clip. Session mode is separately muted. A sound description needs interval-specific listening provenance; a model's `sounds_present` field is not itself a human review. The public package leaves native output in source-review-pending state and never wires it automatically into persona scoring.

## Temporal and scoring boundaries

The initial forecast precedes the first executed action and uses only the first viewport. Terminal interest and editorial feedback are retrospective. A transcript that reaches the closing may finish without optional methods or all media; finish does not mean comprehension. Caps and failures remain distinct from finish/abandon. A partial read cannot be assigned a conditional finish time as if it completed.

Clocks are accounting constructs: read durations are elicited, interaction costs are authored and playback positions are browser measurements. System/API latency is separate. The request auditor reconstructs permitted context and checks recorded geometry, hashes and clocks; it cannot prove that a hostile host did not fabricate its own recordings.

## Comparisons

Predeclare article identity, persona/scope, runtime, exposure policy, model/settings, action/time caps, maximum calls and outcome handling. Keep them fixed across arms. Preserve invalid attempts and missing outcomes. Never substitute a historical control or silently retry a favorable response. The summary case study contains one trace per arm with unequal revealed content; it cannot isolate an editorial treatment effect.

## Calibration and value

Use real-reader measurements on a declared target population and held-out articles. Distinguish prediction accuracy, useful editorial decisions and operating cost, including preparation, review and exceptions. Evaluate against the actual incumbent editorial workflow. A polished replay or an author's preference is not validation of those outcomes.
