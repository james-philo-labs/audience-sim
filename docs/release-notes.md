# Public package 0.2

Adds selected-post role scope, constrained paired-image/table/callout formatting and inline emphasis/HTTPS links, explicit interest anchors, bounded broken-media metadata recovery and clean RPC shutdown, and read-only section/clock summaries. These changes have offline software tests. They do not validate human predictions, provider compatibility or editorial improvement. The public study view now presents the recorded nine-run 3DCodeVerse result; the earlier Opus replay remains separate at `/opus.html`. Added a metric dictionary, explicit feedback-to-design mapping, public-safe JSON/CSV and static study UI source. No raw article/media or requests are included. Human validation remains unmeasured, and publishing the results makes no new provider calls.

# Public package 0.1

This is a separately versioned portable derivative. The historical text harness 0.2, native observer 0.1, persona-scope fix 0.2 and browser session runtime 0.4 informed the selected source. The public package does not rename itself historical runtime 0.4.

Changes for this release:

- Explicit article, bundle, model and persona inputs replace workstation paths and case-specific defaults.
- Approved persona projection is applied to both the text and session entrypoints.
- A small escaped-text article specification replaces the production article renderer and local font dependencies.
- Playwright resolves from a lockfile-managed local package, with optional explicit executable configuration.
- User-supplied cost-rate estimates replace historical hard-coded pricing assumptions; live session requests have a 20 MB serialized-input cap.
- Supporting validator/persona/media implementations are sealed along with prepared session inputs.
- An authored policy exercises the browser/request/audit contract without provider usage and receives a distinct non-simulated-read audit status.
- Historical data are summarized with exclusions and separate studies intact; raw archives, private operational records and large media stay out.

No new audience-model inference or real-reader measurement was performed for this publication. A live integration check is a separately authorized operation, not a requirement of CI. Behavior equivalence between this public derivative and historical runs has not been established.
